# Visionneuse - outil de visionnage photos

## ⚙️ Prérequis

- Node.js

## 🧩 Installation et lancement

1. **Cloner le dépôt :**
```bash
git clone https://github.com/Yann-vdv/Visionneuse
```
2. **Configuration :**
```bash
Ctrl Shift C
```
3. **Installer les dépendances :**
```bash
npm install
```
4. **Lancer l'application :**
```bash
npm start
```
5. **Fermer l'application :**
```bash
Alt F4
```
6. **Ouvrir les logs :**
```bash
Ctrl Shift l
```
